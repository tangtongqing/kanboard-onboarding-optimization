## 3. P0 用户故事

### US001：新手从模板开始创建项目

| 项目 | 内容 |
|---|---|
| 故事编号 | US001 |
| 作为 | 初次使用看板工具的学生/个人开发者/轻量团队负责人 |
| 我想要 | 在新建项目时选择"从模板开始"，从 4 个内置场景模板中选择一个 |
| 以便 | 不需要自己从零设计列结构，直接获得一个符合我使用场景的看板框架 |
| 优先级 | P0 |
| 来源需求 | R001, R002 |

**前置条件**：
- 用户已登录（静态原型中默认已登录）
- 用户在项目列表页或首页

**主流程**：
1. 用户点击"新建项目"按钮
2. 弹出创建向导弹窗
3. 用户看到两种创建方式："空白项目"和"从模板开始" `[待验证：默认选中哪个]`
4. 用户选择"从模板开始"
5. 展示 4 个模板卡片：个人学习项目、求职准备项目、小团队迭代、Bug 跟踪
6. 用户点击选择一个模板

**异常/边界情况**：
- 模板卡片在移动端（390px）收为单列，可纵向滚动
- 模板选择后可切换到另一个模板
- 模板选择后可切换回"空白项目"

**验收标准**：

```gherkin
Given 用户在项目列表页
When 用户点击"新建项目"按钮
Then 弹出创建向导弹窗，展示"空白项目"和"从模板开始"两种入口

Given 创建向导弹窗已打开
When 用户选择"从模板开始"
Then 展示 4 个模板卡片，包含模板名称和场景描述

Given 模板卡片已展示
When 用户点击一个模板卡片
Then 该模板卡片高亮，展示"预览并创建"按钮

Given 用户已选择模板
When 用户切换选择另一个模板
Then 新模板高亮，"预览并创建"按钮更新为新模板

Given 移动端 390px 宽度
When 创建向导弹窗打开
Then 模板卡片收为单列，无横向溢出
```

**待验证点**：
- 创建向导弹窗打开时，默认应该选中"从模板开始"还是"空白项目"？ `[待验证：PD-002 可用性测试]`
- 4 个模板是否覆盖目标用户的核心场景？ `[待验证：PD-002 访谈确认]`

### US002：新手预览模板内容

| 项目 | 内容 |
|---|---|
| 故事编号 | US002 |
| 作为 | 选择模板的新手用户 |
| 我想要 | 在创建项目前预览模板的列结构和示例任务卡 |
| 以便 | 确认模板是否适合我的需求，避免创建后发现不合适 |
| 优先级 | P0 |
| 来源需求 | R005 |

**前置条件**：
- 用户已在 US001 中选择了一个模板

**主流程**：
1. 用户在模板选择后点击"预览并创建"按钮
2. 进入模板预览界面
3. 展示模板的列名、列顺序
4. 展示每列的示例任务卡（标题、描述、负责人、优先级、截止时间）
5. 用户滚动预览完整内容
6. 用户点击"创建项目"按钮

**异常/边界情况**：
- 预览区可纵向滚动
- 用户可点击"返回选择"回到模板选择
- 预览区展示创建后的预计效果

**验收标准**：

```gherkin
Given 用户已选择模板并点击"预览并创建"
When 进入模板预览界面
Then 展示模板的列名和列顺序

Given 模板预览界面已展示
When 用户查看预览内容
Then 每列展示示例任务卡，包含标题、描述、负责人、优先级、截止时间

Given 预览内容超出可视区域
When 用户滚动预览区
Then 可查看完整列结构和所有示例卡

Given 用户在预览界面
When 用户点击"返回选择"
Then 回到模板选择界面，之前的选择保留

Given 用户在预览界面
When 用户点击"创建项目"
Then 进入创建流程
```

**待验证点**：
- 预览内容是否足够帮助用户判断模板是否合适？ `[待验证：PD-002 可用性测试]`

| 优先级 | P0 |

- 创建成功后弹窗立即关闭

```gherkin

When 创建成功
Then 弹窗关闭

Given 创建成功
When 弹窗关闭后
Then 项目列表新增该项目

Given 新项目已添加到列表
When 列表更新后
Then 自动切换到新项目

Given 已切换到新项目
When 查看看板
Then 展示模板定义的列结构

Given 已切换到新项目
When 查看看板
Then 展示模板定义的示例任务卡
```

**待验证点**：
- 创建成功后的跳转是否流畅？ `[待验证：PD-002 可用性测试]`

### US004：新手修改示例卡

| 项目 | 内容 |
|---|---|
| 故事编号 | US004 |
| 作为 | 已通过模板创建项目的新手用户 |
| 我想要 | 修改示例任务卡的标题、描述、负责人、优先级、截止时间等字段 |
| 以便 | 把示例卡转化为我自己的真实任务 |
| 优先级 | P0 |
| 来源需求 | R007 |

**前置条件**：
- 用户已通过模板创建项目
- 看板中存在示例任务卡

**主流程**：
1. 用户在看板中点击一张示例任务卡
2. 打开任务详情弹窗
3. 用户修改任务标题
4. 用户修改任务描述
5. 用户修改负责人、优先级、截止时间等字段
6. 用户保存修改
7. 看板中该卡片更新为修改后的内容

**异常/边界情况**：
- 示例卡修改后不可恢复为原始示例内容
- 修改过程中可取消，不保存修改
- 可修改任意字段，不强制必填

**验收标准**：

```gherkin
Given 看板中存在示例任务卡
When 用户点击一张示例任务卡
Then 打开任务详情弹窗，展示示例卡内容

Given 任务详情弹窗已打开
When 用户修改任务标题
Then 标题输入框更新为新内容

Given 用户已修改任务内容
When 用户点击保存
Then 弹窗关闭，看板中该卡片更新为修改后的内容

Given 用户已修改任务内容
When 用户点击取消
Then 弹窗关闭，示例卡保持原样
```

**待验证点**：
- 用户是否能理解如何修改示例卡？ `[待验证：PD-002 可用性测试]`
- 用户是否会把示例卡修改为自己的任务？ `[待验证：PD-002 观察]`

### US005：新手删除示例卡

| 项目 | 内容 |
|---|---|
| 故事编号 | US005 |
| 作为 | 已通过模板创建项目的新手用户 |
| 我想要 | 删除不需要的示例任务卡 |
| 以便 | 看板只保留我真实的任务 |
| 优先级 | P0 |
| 来源需求 | R007 |

**前置条件**：
- 用户已通过模板创建项目
- 看板中存在示例任务卡

**主流程**：
1. 用户在看板中找到不需要的示例卡
2. 用户点击示例卡的删除按钮（或右键菜单）
3. 弹出确认删除对话框
4. 用户确认删除
5. 示例卡从看板中移除

**异常/边界情况**：
- 删除操作需要确认，防止误删
- 删除后不可恢复
- 删除后该列的任务数更新

**验收标准**：

```gherkin
Given 看板中存在示例任务卡
When 用户点击示例卡的删除按钮
Then 弹出确认删除对话框

Given 确认删除对话框已弹出
When 用户点击确认
Then 示例卡从看板中移除

Given 确认删除对话框已弹出
When 用户点击取消
Then 对话框关闭，示例卡保留

Given 示例卡已删除
When 查看该列
Then 任务数更新为删除后的数量
```

**待验证点**：
- 用户是否会删除示例卡？删除比例是多少？ `[待验证：PD-002 可用性测试]`

|---|---|
| 故事编号 | US006 |
| 作为 | 已有看板使用经验的老用户 |
| 我想要 | 快速创建一个空白项目，不被模板推荐干扰 |
| 以便 | 保持原有使用习惯，高效创建新项目 |
| 优先级 | P0 |
| 来源需求 | R008 |

- 用户已登录
- 用户在项目列表页或首页

```gherkin
Given 新项目已创建
```

### US007：项目名称必填错误处理

| 故事编号 | US007 |

- 创建向导弹窗已打开
- 项目名称输入框为空

**主流程**：
1. 用户在项目名称为空时点击"创建项目"按钮
2. 项目名称输入框下方展示错误提示

**异常/边界情况**：
- 错误提示文案："请输入项目名称"

- 输入框边框在输入后恢复正常

**验收标准**：

```gherkin
Given 创建向导弹窗已打开
And 项目名称输入框为空
When 用户点击"创建项目"按钮
Then 项目名称输入框下方展示错误提示"请输入项目名称"

Given 错误提示已展示
When 查看项目名称输入框
Then 输入框边框变红

Given 错误提示已展示
When 用户在项目名称输入框中输入内容
Then 错误提示自动消失

Given 用户已输入项目名称
When 查看输入框
Then 边框恢复正常颜色
```

**待验证点**：
- 无（错误处理是确定性需求）

### US009：字段微文案说明

| 项目 | 内容 |
|---|---|
| 故事编号 | US009 |
| 作为 | 填写任务字段的新手用户 |
| 我想要 | 在负责人、优先级、截止时间等字段旁看到简短说明 |
| 以便 | 理解每个字段的含义和填写方式 |

| 来源需求 | R009 |

**前置条件**：
- 用户在任务详情弹窗中

2. 在负责人、优先级、截止时间字段旁看到微文案说明

```gherkin
Given 任务详情弹窗已打开
When 用户查看负责人字段
Then 字段旁展示微文案"指定任务负责人，用于协作分工"

Given 任务详情弹窗已打开
When 用户查看优先级字段
Then 字段旁展示微文案"设置任务优先级：紧急、高、中、低"

Given 任务详情弹窗已打开
When 用户查看截止时间字段
Then 字段旁展示微文案"设置任务截止日期，用于时间管理"
```

### US010：创建后轻提示

| 项目 | 内容 |
|---|---|
| 故事编号 | US010 |
| 作为 | 第一次通过模板创建项目的用户 |
| 我想要 | 创建后看到轻提示，了解如何使用看板 |

| 优先级 | P1 |
| 来源需求 | R010 |

**前置条件**：
- 用户第一次通过模板创建项目

**主流程**：
1. 用户创建项目成功
2. 看板顶部展示轻提示
3. 提示文案："拖动卡片到不同列，代表任务进展。你可以修改或删除示例卡。"
4. 用户点击关闭或等待自动消失

**异常/边界情况**：
- 轻提示不能遮挡看板列标题或任务卡。
- 用户关闭后，不应在同一项目中反复出现。
- "第一次"的判断维度待定：可按用户维度，也可按项目维度，需研究后确认。

**验收标准**：

```gherkin
Given 用户第一次通过模板创建项目
When 创建成功后进入看板
Then 看板顶部展示轻提示

Given 轻提示已展示
When 用户查看提示内容
Then 展示"拖动卡片到不同列，代表任务进展。你可以修改或删除示例卡。"

Given 轻提示已展示
When 用户点击关闭按钮
Then 轻提示消失

Given 轻提示已展示
When 用户不操作
Then 轻提示在 5 秒后自动消失
```

**待验证点**：
- 轻提示是否真的有帮助？ `[待验证：PD-002 可用性测试]`
- 自动消失时长是否过短或过长？ `[待验证：PD-002 观察]`

- 自定义模板不应覆盖系统内置模板。

```gherkin
Given 用户有一个已配置好的项目

Then 弹出保存模板弹窗，展示模板名称和描述输入

Given 保存模板弹窗已打开
When 用户输入模板名称并确认
Then 模板保存成功

Given 模板已保存
When 用户新建项目并选择"从模板开始"
Then 自定义模板出现在模板列表中
```

**待验证点**：
- 用户是否真的需要保存自定义模板？ `[待验证：PD-002 访谈确认]`
