# 插件进阶扩展补齐说明 V0.8.25

## 本轮目标
在 V0.8.24 已补齐认证 provider、自动动作和通知类型之后，本轮继续根据 Kanboard 官网插件开发文档补齐更底层的插件扩展点，让“扩展能力”不再只停留在认证和通知，而能覆盖插件页面、外部系统接入、数据库迁移和二次开发 override。

## 本轮新增
- 新增 `state.extensions.advanced.authorization`，覆盖 Application / Project 两类 AccessMap、Controller、Action、Role、项目角色检查与只读 fallback。
- 新增 `state.extensions.advanced.routes`，覆盖自定义路由 URL、Controller、Action、Plugin、链接输出类型、CSRF 与 URL rewriting 检查。
- 新增 `state.extensions.advanced.providers`，覆盖 Avatar Provider、Custom Group Provider、External Link Provider、External Task Provider 与 Mail Transport 注册。
- 新增 `state.extensions.advanced.schema`，覆盖 Schema 迁移版本、驱动文件、表名、事务回滚与迁移模拟。
- 新增 `state.extensions.advanced.events`，覆盖 Helper 注册、自定义事件注册/监听、模板 override、formatter override 与 CSP override 风险提示。
- 在“扩展能力”弹窗中新增进阶配置区、代码预览区、风险检查与模拟日志。
- 将 localStorage key 升级为 `kanboard-static-v0825`，并将项目 JSON 导出版本同步为 `kanboard-static-v0825`。

## 产品判断
- AccessMap 与 Custom Routes 是“插件页面能不能安全出现”的基础能力，应该和认证、通知分开表达。
- Provider 类能力本质是 Kanboard 对外部系统的连接点，适合放进统一的“Provider 接入”配置区，而不是散落成多个小入口。
- Schema 迁移、Helper、Events、Overrides 更偏开发者能力，但在静态复现里应该通过代码预览和风险提示显性化，方便后续写 PRD 时解释给开发。
- CSP override 属于高风险能力，本轮只做可见配置与风险提示，不把它包装成普通开关。
