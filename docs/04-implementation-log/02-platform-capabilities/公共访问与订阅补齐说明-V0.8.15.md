## 官网核对

Kanboard 支持项目和用户级 iCalendar 订阅，项目日历只展示所选项目任务；该订阅是只读的，并需要开启公共访问。RSS/Atom 订阅支持项目和用户活动流，项目 feed 只包含项目活动，也需要在项目设置或用户资料中开启公共访问。Project API 也包含开启/关闭项目公共访问的方法。

参考：

- iCalendar Subscriptions 文档：https://docs.kanboard.org/v1/user/ical/
- RSS/Atom Subscriptions 文档：https://docs.kanboard.org/v1/user/rss/
- Project API 公共访问能力：https://docs.kanboard.org/v1/api/project_procedures/

## 本轮补齐

### 1. 公共访问开关

项目设置新增 `开启公共访问与订阅`：

- 默认关闭，避免项目资料被误设为公开。
- 开启后保存到 `project.settings.publicAccessEnabled`。
- 每个项目生成独立 `publicToken`，用于模拟订阅链接。

### 2. 订阅入口

顶部新增 `订阅`：

- 展示公共访问状态。
- 展示可进入 iCalendar feed 的任务数量。
- 展示可进入 RSS/Atom feed 的项目活动数量。
- 公共访问关闭时订阅链接不可用。

### 3. iCalendar 与 RSS/Atom 链接

订阅弹窗生成两类静态模拟链接：

- `calendar.ics`：表达项目任务日期订阅。
- `activity.atom`：表达项目活动流订阅。

复制按钮在静态原型中采用“选中链接 + 状态反馈”的方式表达，不调用真实剪贴板权限。

## 产品判断

订阅能力不是“新增任务”的主路径，但它解决的是项目与外部工具的同步问题。对产品经理工作流来说，iCalendar 适合把截止日和计划节点放进日历工具，RSS/Atom 适合让项目活动可以被外部信息流追踪。

本轮不实现真实公共 URL、真实 token 校验、真实 iCalendar/RSS 内容生成，也不做服务器端访问控制；只复现信息架构、可用状态、链接表达和静态交互路径。
