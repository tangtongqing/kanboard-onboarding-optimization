## 官网核对

Kanboard 官方 CLI 支持任务、子任务、任务流转和每日汇总等 CSV 导出。官方 API 文档说明 Application API 可用于迁移/导入数据、从外部系统创建任务，Task API 支持创建、查询、搜索、移动和复制任务。

参考：

- Command Line Interface / CSV Export 文档：https://docs.kanboard.org/v1/admin/cli/
- API Reference 文档：https://docs.kanboard.org/v1/api/
- Task API Procedures 文档：https://docs.kanboard.org/v1/api/task_procedures/

## 本轮补齐

### 1. 导入导出入口

顶部新增 `导入导出`：

- 展示当前导出项目、任务数、子任务数、项目文件数。
- 支持生成导出预览。
- 支持选中导出内容，便于复制到外部工具。

### 2. CSV 导出

新增两类静态 CSV：

- `任务 CSV`：导出任务标题、列、泳道、负责人、分类、优先级、截止日、状态、预估、实际耗时和标签。
- `子任务 CSV`：导出任务 ID、任务标题、子任务 ID、子任务标题和完成状态。

### 3. 项目 JSON 备份

新增 `项目 JSON 备份`：

- 导出当前项目的列、泳道、任务、设置、文件、自动化和通知等结构。
- 标记 `exportVersion: kanboard-static-v0816`。
- 用于静态原型内的迁移和恢复演示。

### 4. JSON 导入为新项目

新增粘贴 JSON 导入：

- 预览导入项目名称、列数、泳道数和任务数。
- 导入时生成新的项目、列、泳道、任务、子任务、附件和自动化 ID，避免与现有项目冲突。
- 导入后自动切换到新项目。

## 产品判断

真实 Kanboard 的批量导出更多是管理员/运维侧能力，导入和迁移通常依赖 API 或脚本。静态原型不适合做真实文件下载、服务器导入和权限校验，所以本轮先复现用户可理解的导入导出路径：看见格式、复制内容、粘贴 JSON、导入为新项目。

这也为后续作品集表达提供了一个清晰边界：前端原型负责信息架构和流程证明，真实数据迁移需要后端 API、文件下载和权限系统支撑。
