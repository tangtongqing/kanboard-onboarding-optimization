# 首次核心操作轻引导前端实现（PD-019C）

> 实施阶段：PD-019C / PD-019C-R1 / PD-019C-R2  
> 最终修复方：Codex  
> 完成日期：2026-07-08

---

## 1. 实现摘要

本轮将“首次核心操作轻引导”落入静态 Kanboard 原型，覆盖首次拖拽、首次编辑、首次删除、首次任务菜单四类低打扰提示。

实现目标是让新手在真实看板操作中理解卡片可以拖动、可以编辑、删除不可恢复、任务菜单还有更多动作，同时避免遮挡 PD-018 新手清单、Tooltip、Dialog 和移动端 Drawer。

---

## 2. 关键入口

| 能力 | 关键函数 / 选择器 | 行为 |
| --- | --- | --- |
| 首次拖拽提示 | `createCardElement(...)`、`.card`、`showPopover(...)` | 桌面端 hover/focus 第一张卡约 0.8 秒后展示 Popover；`dragstart` 后写入 `completed`。 |
| 首次编辑提示 | `.first-action-guidance-edit-dot`、`.first-action-guidance-inline`、`openCardDialog(...)` | 桌面端编辑点 hover/focus 展示 Popover；移动端展示 inline strip；打开编辑弹窗后写入 `completed`。 |
| 首次删除确认 | `deleteEditingCard()`、`performDeleteEditingCard()`、`#firstDeleteConfirmDialog` | 首次删除先展示专属确认层；取消保留卡片，确认执行真实删除。 |
| 首次任务菜单提示 | `.card .board-menu summary`、`completeTaskMenuGuidance()` | 首次打开任务菜单展示发现提示，菜单项仍可点击，点击菜单项后写入 `completed`。 |
| 互斥避让 | `isGuidanceSuppressed()`、`destroyActivePopover(true)` | Dialog、Checklist、Drawer、Tooltip 打开时销毁轻引导并记录 suppressed。 |

## 3. 状态机与本地埋点

状态存储 key：

```text
kanboard:first-action-guidance:{projectId}
```

字段：

```text
dragCard
editCard
deleteCard
taskMenu
updatedAt
```

允许状态：

```text
not_seen
shown
dismissed
completed
suppressed
```

事件写入：

```text
kanboard:activation-events
```

PD-019C 事件：

```text
first_action_guidance_shown
first_action_guidance_dismissed
first_action_guidance_completed
first_action_guidance_suppressed
first_delete_confirm_viewed
first_delete_cancelled
first_delete_confirmed
```

最终 R2 修复确认：

- 拖拽提示 shown payload 包含 `field: "dragCard"`。
- 编辑提示 shown payload 包含 `field: "editCard"`。
- 菜单提示 shown payload 包含 `field: "taskMenu"`。
- 删除相关事件包含 `field: "deleteCard"` 与 `cardId`。
- suppressed 事件包含 `field` 与 `reason`。
- 事件数组达到 100 条后保留最近 90 条，再写入新事件；自动化断言最终为 91 条。

---

## 4. 移动端与互斥策略

- 390px 视口不渲染桌面 hover Popover。
- 移动端编辑提示使用 `.first-action-guidance-inline`。
- 首次删除确认在 480px 以下转为 Bottom Sheet，按钮高度不低于 44px。
- Checklist panel 展开、mobile drawer 打开、任意非首次删除 Dialog 打开、Tooltip 显示时，轻引导主动销毁。
- scroll / resize 会销毁当前 Popover，避免定位错位。

## 5. 测试覆盖

`tests/static-feature-audit-v08.js` 已新增 PD-019C 真实交互覆盖：

- 空白项目无卡时无提示，创建第一张真实卡后出现编辑入口。

- 拖拽 shown 事件断言 `field: "dragCard"`。
- Dialog 打开时 Popover suppressed，断言 `field` 与 `reason`。
- 编辑点 hover 展示编辑 Popover，断言 `field: "editCard"`。
- 双击卡片打开编辑弹窗并将 `editCard` 写入 `completed`。
- 首次删除自定义确认层的取消和确认分支。
- 二次删除不再展示首次说明层。
- 菜单提示展示并断言 `field: "taskMenu"`。
- `dragstart` 写入 `dragCard: "completed"`。
- 390px 下无横向溢出，移动端使用 inline strip。
- `kanboard:activation-events` 超限裁剪。
