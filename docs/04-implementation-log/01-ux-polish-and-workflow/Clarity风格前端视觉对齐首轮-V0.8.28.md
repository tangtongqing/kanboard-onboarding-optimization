## 本轮调整

- 将整体基调从深色侧栏和较重后台风格调整为浅色 SaaS 工作台：白色侧栏、浅灰页面底、白色面板和轻边框。
- 保留 Kanboard 的高信息密度，但把统计卡、筛选区、看板列、任务卡、弹窗和表单统一到更克制的紫色主色系统。
- 将按钮、分段控件、输入框、标签、风险提示和状态胶囊统一到 8px 左右的圆角和更稳定的间距。
- 移动端把顶部操作按钮整理成横向命令条，避免按钮纵向堆叠把核心内容推到首屏之外。
- 为兼容既有静态审计，将 `preview-section` 的 `#f8fafc` 面板背景保持为显式规则。

## 关键判断

- 这轮不是继续扩张 Admin、Settings、数据库、安全配置或剩余 API Procedure 的系统级功能复现。
- 原 V0.8.28 系统级功能扩张主线继续暂停；本次 V0.8.28 重新定义为前端视觉对齐首轮。
- 当前交付是静态原型视觉层的第一轮对齐，不等同于所有页面都已经完成逐帧级别的最终设计精修。
