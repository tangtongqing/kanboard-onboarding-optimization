# 验证证据范围决策 2026-06-22

## 决策

本项目不安排招募式真人测试。PD-010D 与 PD-012 的真人招募、主持、P01~P08 记录和样本汇总不再是项目目标或 Gate 条件。

项目以 PD-010D-R 已收集的公开真实案例作为二手研究证据基线，包括：

- Kanboard 官方文档中的产品能力与工作流事实；
- Kanboard GitHub issue 中的真实问题、设备环境和使用场景；
- Hacker News 公开评论中的长期使用、替换和体验反馈。

## Gate 影响

- PD-011 状态：`Go（二手研究口径）`。
- PD-011A 先产出恰好 3 个视觉方向，不直接修改生产页面。
- 项目负责人选择方向后，PD-011B 可进入高保真实现。
- 交付验收改为设计 QA、桌面与 390px 真实设备/浏览器检查、可访问性检查和完整自动审计。

## 证据边界

- 公开案例是真实用户产生的公开材料，但在本项目中属于二手研究，不等于本项目主持的真人测试。
- S01~S04 属于基于证据的模拟画像，不是参与者，也不计样本。
- 不得声称完成访谈、招募式可用性测试、A/B 实验或统计验证。
- V03~V06 的低置信选择通过三方向比较、项目负责人决策和设备检查保持可逆。

## 被取代事项

- 原 PD-010D 招募式真人测试任务：取消，不作为最终归档文件保留。
- PD-010A §8 真人测试执行包：归档，不执行。
- PD-012 招募式正式可用性测试：移出项目范围。

本决策是后续聊天窗口、任务发布、README、作品集叙事和 Gate 判断的当前有效口径。
