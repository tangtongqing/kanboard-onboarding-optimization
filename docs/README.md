## 证据边界

- 未执行招募式真人测试；用户问题与产品效果仍需验证。
- 移动端验证基于 Chromium 390px 视口，不等于真实 iOS/Android 设备测试。
- 自动化检查证明原型功能与状态可达，不证明转化、留存或满意度提升。
- 静态演示使用浏览器 `localStorage`，无后端、账号和跨设备同步。

## 维护原则

1. MRD 负责“为什么做、为谁做、市场需要什么”。
2. PRD 负责“做什么、如何验收、先后顺序是什么”。
3. UX 文档只补充 PRD 无法承载的流程、状态和视觉细节。
4. 版本实现统一更新[版本记录](00-project-governance/版本记录.md)，不再新增单版本说明。
5. 测试报告优先更新现有总报告，不为一次小修复新增文件。
6. 链接到主文档，不复制同一段结论。
