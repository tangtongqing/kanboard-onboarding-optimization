# 文档中心

本目录保存项目说明、产品设计产物、版本迭代记录和验收资料。根目录只保留运行入口、源码、测试、设计图和总览 README。

## 目录结构

| 目录 | 内容 | 适用场景 |
|---|---|---|
| `00-project-governance/` | 项目启动、路线图、生命周期基线、协作方案、项目结构、版本记录 | 查看项目为什么做、现在做到哪、后续怎么协作 |
| `01-research-discovery/` | 竞品分析、用户假设、产品机会、用户研究计划 | 查看问题定义、目标用户、研究输入 |
| `02-requirements/` | PRD 骨架、用户故事、验收标准 | 查看需求范围、故事拆分、验收口径 |
| `03-ux-design/` | 流程图、信息架构、交互状态、设计原则、页面 Brief 与设计系统 | 查看 UX 结构、状态、页面和视觉约束 |
| `04-implementation-log/` | V0.3~V0.8.27 静态原型与功能复现说明 | 查看历史实现迭代和静态能力补齐记录 |
| `05-validation/` | 静态功能验收报告 | 查看测试与验收结论 |

## 推荐阅读路径

1. 先读 `00-project-governance/产品生命周期真实进度基线.md`，确认真实阶段。
2. 再读 `01-research-discovery/产品机会说明与问题定义-PD-001.md` 和 `01-research-discovery/用户研究计划与访谈脚本-PD-002.md`。
3. 继续读 `02-requirements/功能优化PRD骨架-PD-003.md` 与 `02-requirements/用户故事与验收标准-PD-004.md`。
4. 进入 `03-ux-design/` 查看 PD-005~PD-010 的流程、状态、页面 Brief、设计系统和低保真线框。
5. 如需追溯已实现静态能力，再看 `04-implementation-log/` 和 `05-validation/`。

## 维护规则

- 新的产品设计文档优先放入 `01-research-discovery/`、`02-requirements/` 或 `03-ux-design/`，具体归档规则见 `00-project-governance/项目结构说明.md`。
- 新的静态实现说明放入 `04-implementation-log/`，不要再堆到项目根目录。
- 新的测试、验收、复核类报告放入 `05-validation/` 或 `.agent-ops/mimo/outbox/`。
- 根目录 `README.md` 只保留项目总览和关键入口，不再承载所有细节。
