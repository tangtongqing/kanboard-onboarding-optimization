## 五、修复说明

R2 主要修复：

1. `app.js` 中真实调用 `initFieldTooltips()`，并将 Tooltip 改为一次性事件委托，避免动态弹窗和重复渲染后丢失监听器。
2. Tooltip 会优先挂载到当前打开的 `dialog`，避免被浏览器 Top Layer 遮挡。
3. Tooltip 使用 fixed 定位和 viewport clamp，桌面与 390px 移动端都能完整显示。
4. 移动端 `<=480px` 下只通过 tap/click 打开 Tooltip，避免鼠标模拟 hover 造成误开误关。
