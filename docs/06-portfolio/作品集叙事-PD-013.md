## 1. 作品集一句话

我围绕新手从"空白创建冷启动"到"安全完成首次有效操作"的完整上手路径，设计并验证了一套以场景模板为起点、新手 Checklist 为驱动、一次性轻引导 Popover 为阻尼的低干扰看板激活体验，并在可运行原型中无 Mock 跑通了全量 449 项静态审计。

## 2. 项目背景

Kanboard 是经典开源看板工具，能力完整但新手创建项目时默认从空白结构开始。对第一次管理课程项目、个人学习计划、求职作品集或小团队任务的人来说，主要困难不是"不知道怎么点按钮"，而是不知道如何把一个模糊目标拆成可执行的看板结构。

本项目选择"新手项目创建与任务拆解体验优化"作为核心命题，刻意限制系统级能力扩张，把产品设计与实现闭环推进到可以展示完整"用户上手激活与首次核心操作防护"的程度。

## 3. 用户问题

| 用户场景 | 典型阻碍 | 设计机会 |
|---|---|---|
| 学生准备课程项目或作品集 | 不知道应该建哪些列、任务粒度如何拆 | 用场景模板给出起步结构 |
| 个人开发者管理个人项目 | 空白看板需要自己配置列和泳道 | 保留空白创建，同时提供结构化模板 |
| 轻量团队负责人启动小项目 | 需要快速对齐阶段和任务样例 | 创建前预览列、泳道和示例任务 |
| 看板新手面临示例卡 | 对高质量示例卡有敬畏感，焦虑失误编辑与删除 | 新手 Checklist 引导首次探索；防误删弹窗拦截删除焦虑 |

核心问题：

> 新用户知道"我要管理任务"，但不知道如何从空白项目拆成可执行看板，也不敢轻举妄动操作它。

## 4. 设计目标

| 目标 | 说明 |
|---|---|
| 降低起步成本 | 从"空白配置"改为"场景模板 + 可编辑示例任务" |
| 新手破冰 Checklist | 用 0/3 -> 3/3 级联进度条驱动用户完成首次编辑、拖动和创建核心探索 |
| 核心动作轻防护 | 首次拖拽与编辑橙色呼吸点气泡轻引导，首次删除自定义对话框拦截 |
| 保留高级用户效率 | 空白项目路径免受任何 Checklist 或 Popover 的干扰 |
| 全链路闭环验证 | 自动化集成测试 + 回归截图 + 真实 LocalStorage 埋点事件序列留存 |

## 6. 优化前后对比

| 维度 | 优化前 | 优化后 |
|---|---|---|
| 创建起点 | 空白项目为主，需要用户自己知道列结构 | 默认提供模板路径，也保留空白项目 |
| 任务拆解 | 创建项目后仍需自己补任务 | 模板生成列、泳道和示例任务 |
| 新手学习方式 | 依赖用户阅读文档，从零理解列/泳道概念 | 0/3 Checklist 驱动，Tooltip 大白话释义，做中教学 |
| 核心操作防护 | 无引导，新手面临生冷操作，删除任务时弹原生 confirm | 首次拖拽/编辑 Popover 气泡，首次删除自定义确认 Dialog 拦截 |
| 界面避让 | 气泡与 Dialog 可能同时存在，认知过载 | Popover 在 Dialog/Tooltip 激活时自动 suppressed 退出 |
| 移动端 | 长内容迷失，模态弹窗溢出屏幕 | 390px inline 提示条 + Bottom Sheet，网格零溢出 |

## 7. 关键取舍

- **不做系统级功能扩张**：V0.8.28 后转为前端视觉对齐与 CSS 债务清理（V0.8.29），后续进入以用户激活为核心的 PD-018/019 阶段；作品集主线优先讲清楚"为什么这样设计"。
- **不虚构真人可用性指标**：使用公开真实案例研究与自动化集成验证作为证据基线，诚实保留真机限制与招募空缺。
- **不虚写 Figma 设计状态**：诚实声明 PD-019B 未物理写入线上 Figma node，但已补齐项目内 SVG/PNG 高保真图稿归档、规格标注和样式文档。
- **保留高级用户效率**：空白项目与老项目路径严格隔离，绝不展示新手 Checklist 或核心操作 Popover。

## 9. 结果与反思

本项目最终形成了一个可运行的高保真静态原型，在无任何 Mock 插桩的前提下跑通了全量 449 项静态集成审计。方案解决的不只是创建流程的结构性困惑，还延伸到新手进入看板后的首批核心操作防护——让用户真正能从"我要管理任务"走到"我安全完成了第一次操作"。

仍需诚实标注的限制：

- 没有执行招募式真人可用性测试。
- 没有接入真实物理设备，本次移动检查为 Chromium 390px 视口仿真。
- Figma 文件是轻量交付稿，不是正式工程级 Design System Library。
- PD-019B 未物理写入线上 Figma node；项目内已补齐 12 张 SVG/PNG 高保真图稿、总览页、规格标注与样式文档。
- 研究结论来自公开材料、专家判断和静态原型自动回归走查，置信度低于真实用户样本。

## 10. 作品集 10 页展示结构

(详细的最终展示包大纲与材料索引见 [`最终作品集展示包-PD-014.md`](最终作品集展示包-PD-014.md)；讲述脚本见 [`作品集对外展示包增量升级-PD-020.md`](作品集对外展示包增量升级-PD-020.md))

1. **问题背景与用户冷启动困境**：Kanboard 强大但空白创建对新手成本极高。
2. **研究证据与项目边界**：基于 GitHub 公开 Issue 及专家走查，确立优化边界和诚实限制。
3. **设计目标与非目标**：以"做中教学、低干扰、高级用户隔离"为原则。
4. **创建前结构化模板与示例卡**：4 种初始模板，展示可编辑预览机制与示例卡质量指引。
5. **创建后 0/3~3/3 新手激活 Checklist**：持久化状态机，级联进度与 Toast 轻反馈。
6. **字段 Tooltip 与术语白话解释**：消除术语壁垒，支持自适应边缘避让。
7. **首次核心操作轻引导**：拖拽 Popover、呼吸红点双击引导、首次删除确认 Dialog 拦截、任务菜单探索气泡。
8. **移动端 390px 适配**：Bottom Sheet 手势、inline 装饰提示条、网格零溢出。
9. **验证证据**：449 checks 集成测试全绿，26 张归档截图，本地 LocalStorage 与埋点日志。
10. **限制、反思与下一步**：真机与真人测试空缺的坦白，以及可选的后续研究验证方向。
