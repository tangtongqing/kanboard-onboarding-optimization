| 等级 | 数量 | 说明 |

| P1 | 8 | 影响 Clarity/D02 风格一致性或专业感 |
| P2 | 6 | 后续 polish 细节 |

## 4. P0 问题

### P0-1：移动端顶部操作栏挤压首屏内容

| 项 | 内容 |
|---|---|
| 页面范围 | F45 全局导航与看板移动端 |
| 证据来源 | `设计图/kanboard-v0.8.28-clarity-mobile.png` + `styles.css:3274-3287` |
| 风险 | 390px 下 `.topbar-actions` 使用 `flex-wrap: nowrap` + `overflow-x: auto`，导致操作按钮横向滚动，但首屏看板内容被推到下方，用户需要滚动才能看到第一列 |
| 建议动作 | Mimo 后续实现：将操作按钮收为"更多"下拉菜单，或使用横向滚动指示器让用户知道可滑动 |
| 验收标准 | 390px 下首屏至少可见看板第一列的前 2 张任务卡 |

### P0-2：移动端弹窗长内容底部操作遮挡

| 项 | 内容 |
|---|---|
| 页面范围 | F46 任务详情与移动操作 |
| 证据来源 | `styles.css:1419-1438` + PD-011D 浏览器检查 |
| 风险 | 虽然 PD-010B 已修复 R08（sticky 底部操作），但在长表单弹窗（如项目设置、系统设置）中，底部操作 sticky 后仍可能遮挡上方内容，特别是 390px 下输入框获得焦点时键盘弹出 |
| 建议动作 | Mimo 后续实现：为长表单弹窗增加底部 padding，确保内容不被遮挡 |
| 验收标准 | 390px 下长表单弹窗滚动到底部时，最后一条内容可见且不被操作栏遮挡 |

### P0-3：示例卡徽标在 Clarity 紫色主色下对比度不足

| 项 | 内容 |
|---|---|
| 页面范围 | F06 创建成功看板首屏 |
| 证据来源 | `styles.css:3132-3138` + `styles.css:2706-2708` |
| 风险 | Clarity 主色改为 `#5848e8`（紫色），但 `.example-label` 仍使用 `var(--primary)` 和 `var(--primary-soft)`，在浅紫色背景下文字对比度可能不足 4.5:1 |
| 建议动作 | Codex 需要亲自处理：检查紫色主色下示例徽标的对比度，必要时调整徽标颜色 |
| 验收标准 | 示例徽标文字与背景对比度 ≥ 4.5:1 |
