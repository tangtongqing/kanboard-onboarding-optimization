## 1. 全局设计系统规范 (Clarity 风格同步)

所有新增组件与状态设计必须遵循 `PD-009` 设计系统及 `V0.8.29` 静态原型的 Clarity 极简风格：

- **基调颜色**：
  - 主背景色：`#FFFFFF` / 页面底色：`#F9FAFB`
  - 边框与分割线：`#E5E7EB` (1px 实线)

  - 成功状态：`#10B981` (明亮绿)
  - 警告/避坑状态：`#FEF3C7` (浅黄底), `#D97706` (琥珀字)

- **组件规范**：
  - 阴影：低阴影（`0 4px 12px rgba(0, 0, 0, 0.05)`）
  - 圆角：外圆角 `8px`，内部输入框与气泡圆角 `6px`

## 2. 新增高保真 Frame 视觉规格定义 (共 12 张)

以下定义 12 张 Frame 的排版间距、元素坐标、背景色及核心文本：

### 2.1 桌面端看板：Checklist 展开态（初始 0/3）
- **视口**：`1440x900`
- **位置**：浮动悬挂在看板工作区右下角，距离窗口右边缘 `24px`，底边缘 `24px`。
- **画板尺寸**：宽 `320px`，自适应高度。
- **视觉特征**：
  - 背景色 `#FFFFFF`，圆角 `8px`，边框 `1px solid #E5E7EB`，阴影 `0 4px 12px rgba(0, 0, 0, 0.08)`。
  - **头部 (Header)**：高度 `44px`，背景色 `#EEF2F6`，左边显示文字 `新手破冰挑战 (0/3)`（14px, `#1F2937`，粗体），右侧显示折叠箭头 `↓`（向下 chevron 图标）。
  - **清单区域**：上下内边距 `16px`，左右内边距 `16px`。包含三个带有空白复选框的横向栏：
    - `[ ] 双击修改任意一张示例卡片`
    - `[ ] 拖拽任意任务卡片到右侧列`

### 2.2 桌面端看板：Checklist 折叠态

### 2.7 桌面端字段 Tooltip：WIP 限制 Hover 解释
- **位置**：在列配置弹窗中，当鼠标 Hover 到 `WIP 限制` 标签右侧的圆圈问号 `?` 图标时。
- **气泡尺寸**：宽 `240px`，高度自适应。
- **视觉特征**：
  - 黑色半透明背景 `#1F2937`，文字白色 `#FFFFFF`（11px Inter Regular），圆角 `4px`。
  - 气泡底部带有一个向下的三角形小尖角，尖角底部对准问号图标的中心点。
  - 文本内容：`WIP限制：指该步骤允许同时处理的最大卡片数。限制它是为了强迫自己专注推进，防止贪多嚼不烂导致什么都没做完。`

### 2.8 桌面端字段 Tooltip：泳道 Hover 解释
- **位置**：在项目看板新建页面或泳道设置表单，鼠标 Hover 到 `泳道` 右侧的问号 `?` 处。
- **视觉特征**：
  - 同 2.7 样式规范。
  - 文本内容：`泳道：用于横向划分任务的分类通道（如‘个人’与‘团队’），像泳池的分道线一样，让不同类别的任务互不干扰。`

### 2.9 移动端 390px：看板右下角 Checklist 进度气泡
- **视口**：`390x844`
- **位置**：右下角，浮动于看板内容之上，距离右边界 `16px`，下边界 `16px`。
- **视觉特征**：
  - 紧凑的圆形气泡（直径 `48px`），背景色为蓝色 `#2563EB`，白色粗体显示进度 `0/3` 或图标。
  - 带有轻微的向外呼吸微光波圈（表示可交互指引）。

### 2.10 移动端 390px：Checklist Bottom Drawer 展开态
- **视口**：`390x844`
- **位置**：用户点击进度气泡后，从页面底部滑出覆盖看板。
- **画板尺寸**：宽 `390px`，高 `260px`。
- **视觉特征**：
  - 背景色 `#FFFFFF`，仅顶部两个角为 `16px` 大圆角。
  - 页面背景呈 `30%` 透明黑色遮罩遮挡。
  - 面板顶部带有一个灰色横条 Handle（手势操作暗示），右上角有明显的 `✕` 关闭按钮。
  - 内部完整显示三项挑战挑战，字号适当放大至 `14px`，确保触指可读与易点。

### 2.11 移动端 390px：字段 Tooltip Tap 打开状态
- **位置**：移动端输入表单中，用户轻触 WIP 限制旁的 `?` 标志。
- **视觉特征**：
  - 在移动端不直接悬浮小气泡，而是以轻量 Dialog 或在输入框正下方折叠展开的形式呈现 1-2 行的提示，避免手指挡住气泡内容。
  - 轻触气泡外部任意背景，提示框淡出销毁。

### 2.12 移动端 390px：边界排版防溢出检查
- **视口**：`390x844`
- **视觉特征**：
  - 模拟 Tooltip 气泡在极靠近屏幕边缘（例如卡片最右侧字段）时的朝向翻转。
  - 气泡自动向左偏置，三角形尖角非居中，偏向右侧对准问号图标，确保没有任何文字内容超出 `390px` 手机屏幕边界而被裁切。

## 3. 后续实现（PD-018C/D）注意事项

Figma 物理画板已补齐，以下关键设计细节继续作为后续开发与 QA 的输入参数：

1. **Checklist 组件的 Class 与 DOM 树**：
   - 建议在开发阶段，使用 `#onboarding-checklist` 独立容器包裹。
   - 内部三个 `li` 项，分别使用类名 `.task-item`。
2. **状态判定监听器定义**：
   - 任务 1：监听修改表单 `example-card-edit-form` 提交，通过正则判定标题修改。
   - 任务 2：监听列的 `drop` 事件。
   - 任务 3：监听新建卡片事件，且创建出的标题非占位符。
3. **Tooltip 移动端点击避让**：
   - 必须通过 JS 检测当前视口宽度。若宽度小于 `480px`，禁止使用 CSS 的 `:hover` 浮窗，必须注册点击切换（Toggle）事件。
