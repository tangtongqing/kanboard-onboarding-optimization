### F05：W09 状态板

| 项 | 规格 |
|---|---|
| Frame 目标 | 同屏展示 loading/error/success/confirmation 四类状态 |
| 画幅 | 1440 x 1024 |
| 结构 | 四个状态分区，每分区展示触发条件、界面表现、操作 |
| 关键组件 | loading（spinner+文字）、error（红色边框+背景+文字）、success（toast）、confirmation（对话框） |
| 文案与数据 | loading："创建中…"；error："请输入项目名称"；success："已创建：我的产品迭代看板"；confirmation："确定离开吗？未保存的内容将丢失" |
| 可访问性 | loading: aria-live="polite"；error: aria-invalid+aria-describedby；success: aria-live="polite"；confirmation: 焦点进对话框 |
| 高保真注意点 | loading spinner 不显示真实百分比；confirmation "继续编辑"为安全主操作，"放弃并关闭"为危险操作 |

## 7. 组件规格
