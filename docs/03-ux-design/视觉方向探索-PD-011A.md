## 4. 三方向生成原则

### 可以变化的变量

| 变量 | 说明 |
|---|---|
| 信息密度 | 模板卡片展示多少信息、预览区展示多少内容 |
| 视觉层级 | 如何用视觉手段区分主次信息 |
| 状态表达 | loading/error/success/confirmation 的视觉强度 |
| 移动端策略 | 全屏 vs 边距对话框、底部操作的视觉权重 |
| 间距节奏 | 紧凑 vs 宽松的间距选择 |

### 不能变化的结构

| 结构 | 说明 |
|---|---|
| 创建方式二选一 | 必须保留"空白项目"和"从模板开始"两种入口 |
| 4 个内置模板 | 必须覆盖个人学习、求职准备、小团队迭代、Bug 跟踪 |
| 模板预览 | 必须展示列结构、泳道、示例任务 |
| 空白创建路径 | 必须保留一键可见的空白创建路径 |
| 必填校验 | 必须有名称为空的错误处理 |
| 未保存关闭确认 | 必须有 S11 确认对话框 |

### 不能变化的证据边界

| 边界 | 说明 |
|---|---|
| 不使用重渐变/玻璃拟态/大阴影 | 违反产品基调：克制、清晰、可信 |
| 不使用装饰性插画/重复卡片网格 | 违反工作工具定位 |
| 不牺牲空白创建路径 | 违反 DP04 保留高级用户效率 |
| 不把二手研究包装成用户结论 | 违反证据边界 |

## 5. 视觉方向总览表

| 方向 | 名称 | 一句话主张 | 适合的用户 | 核心差异 |
|---|---|---|---|---|
| D01 | Quiet Focus | 用最大留白和最少视觉噪音，让新手安静地做出第一个选择 | 个人学习者、首次使用看板的用户 | 最大留白、渐进披露、弱状态反馈 |

## 6. D01：Quiet Focus

### 6.1 方向主张

用最大留白和最少视觉噪音，让新手安静地做出第一个选择。信息按需展开，不预设用户已经理解看板方法。

### 6.2 适合的用户与风险

| 适合 | 风险 |
|---|---|
| 个人学习者、首次使用看板的用户 | 信息不足可能导致选择犹豫 |
| 不喜欢复杂界面的用户 | 需要更多点击才能看到完整信息 |
| 偏好安静工作环境的用户 | 状态反馈可能不够明显 |

### 6.3 页面处理

| 页面 | 视觉层级 | 布局策略 |
|---|---|---|
| P002 新建项目弹窗 | 极简头部、大面积留白、创建方式用轻量 radio | 弹窗内纵向分区，名称/描述在上，创建方式在中，模板区在下 |
| P004 模板列表 | 4 个模板卡片显示名称、场景一句和列/泳道/示例卡数量，不直接展开列名 | 左列 200px，卡片间距 12px，选中用左侧蓝色边框 |
| P005 模板预览 | 预览区保留列、泳道、示例任务的轻量语义分区，但降低分区背景和标题重量 | 右侧自适应，预览区纵向滚动，底部操作固定 |
| P006 空白创建表单 | 只有名称和描述输入，无额外说明 | 单列纵向，底部操作固定 |
| P009 创建成功看板首屏 | 成功用轻量 toast，不用大色块 | 标准看板布局，示例卡用"示例"徽标 |
| P013 390px 创建向导 | 保留 16px 边距对话框，底部操作 sticky | 单列纵向，模板卡片全宽 |

### 6.4 状态处理

| 状态 | 表达方式 |
|---|---|
| default | 白色背景、灰色边框、最小视觉噪音 |
| selected | 左侧蓝色边框 3px，不用大面积蓝色背景 |
| loading | 按钮文字变为"创建中…"，按钮禁用，不用 spinner |
| error | 红色边框+下方文字，不用红色背景 |
| success | 轻量 toast（右上角，3 秒自动消失），不用大色块 |
| confirmation | 居中对话框，按钮用文字而非图标 |

### 6.5 V03~V06 立场

| 编号 | 立场 |
|---|---|
| V03 | V03a 精简摘要 + 渐进披露：显示名称、场景和数量，复杂模板提供进入详细预览的清晰路径 |
| V04 | V04b 轻量分区：保留列、泳道、示例任务的语义分区，但降低背景和标题视觉重量 |
| V05 | V05a 默认模板+名称在顶部：保持现有代码结构 |
| V06 | V06b 保留 16px 边距：对话框语义清晰，底部操作 sticky |

### 6.6 视觉系统

| 项 | 规则 |
|---|---|
| 颜色 | 沿用现有 17 个 CSS 变量，不新增语义色 |
| 字体 | 沿用 Aptos 字体栈，字号层级不变 |
| 间距 | 偏宽松：弹窗内边距 24px，组件间距 16px，卡片间距 12px |
| 圆角 | 6px 统一，不用大圆角 |
| 边框 | 默认灰色边框，选中/错误用颜色边框 |
| 阴影 | 沿用现有阴影系统，不增加新阴影 |
| 图标 | 不使用装饰性图标，只用必要的操作图标 |
| 动效 | 最少动效，只在 loading/success 时有文字变化 |

### 6.7 可访问性与响应式

| 项 | 规则 |
|---|---|
| 对比度 | 文字 #111827 与背景 #ffffff 对比度 14.5:1 |
| 焦点 | :focus-visible 蓝色 outline 2px |
| 键盘 | Tab/方向键/Enter/Space/ESC 全可达 |
| 读屏 | loading/success/error 用 aria-live 公告 |
| 44px 触摸目标 | 移动端按钮/输入框高度 ≥44px |
| 390px 无横向溢出 | 单列纵向，无横向滚动 |

### 8.6 视觉系统

| 项 | 规则 |
|---|---|
| 颜色 | 沿用现有 17 个 CSS 变量，loading 状态复用主色和 `--primary-soft`，不新增进度语义色 |
| 字体 | 沿用 Aptos 字体栈，示例任务描述用 12px 灰色文字 |
| 间距 | 紧凑：弹窗内边距 16px，组件间距 10px，卡片间距 8px |

| 边框 | 默认灰色边框，选中/错误用颜色边框 |
| 阴影 | 沿用现有阴影系统，不新增大阴影 |
| 图标 | 创建方式 segmented control 有图标，toast 有状态图标+项目名 |
| 动效 | 强反馈但控制时长：loading 有 spinner+弱状态条，success 有淡入，卡片选中有 150-250ms 颜色过渡 |

### 8.7 可访问性与响应式

| 项 | 规则 |
|---|---|
| 对比度 | 紧凑间距下文字对比度仍 ≥4.5:1 |
| 焦点 | :focus-visible 蓝色 outline 2px |
| 键盘 | Tab/方向键/Enter/Space/ESC 全可达 |
| 读屏 | loading/success/error 用 aria-live 公告，错误摘要有 aria-describedby |
| 44px 触摸目标 | 移动端按钮/输入框高度 ≥44px，segmented control 每个按钮 ≥44px |
| 390px 无横向溢出 | 全屏容器，单列纵向，无横向滚动 |
