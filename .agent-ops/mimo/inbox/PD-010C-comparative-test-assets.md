统一实验控制：
1. 从 PD-010 §6 复制真实模板数据，建立“标准数据集”；不得自行发明与现有模板冲突的列、泳道或示例任务。
2. 同一 A/B 组必须使用完全相同的项目名、模板名、场景说明、列名、泳道名、示例任务、按钮文案和状态起点。
3. 同一 A/B 组只允许一个自变量：
   - V03：模板卡片信息密度。
   - V04：预览信息层级。
   - V05：默认创建方式与名称位置（按既定组合比较，不再拆分为两个实验）。

4. 参与者看到的画面不显示 `V03a`、`V03b`、“推荐”、“现状”或任何会暗示优劣的标签；这些编号只出现在主持人索引和图题中。
5. A/B 图的尺寸、灰阶、线宽、字体层级和信息顺序保持一致；除目标自变量外，不增加图标、色彩、装饰、帮助文案或额外交互提示。
6. 每张测试图必须同时标注内部资产编号、目标视口、可操作热点或主持跳转条件，但这些标注放在图外的主持说明中，不污染参与者画面。
