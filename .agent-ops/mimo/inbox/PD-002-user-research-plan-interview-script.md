文档要求：
1. 文档标题使用 `# 用户研究计划与访谈脚本 PD-002`。
2. 必须包含以下章节：
   - 研究目标
   - 当前已知假设
   - 研究对象与招募条件
   - 研究方法
   - 访谈提纲
   - 可用性测试任务
   - 观察指标与记录表
   - 结果分析方法
   - 研究边界与伦理注意事项
   - 输出物与后续如何进入 PD-003 PRD
3. 研究对象至少覆盖：
   - 作品集准备中的学生或产品学习者
   - 个人开发者或工具型用户
   - 轻量团队负责人或小组协作者
4. 可用性测试任务至少包含两条路径：
   - 路径 A：从空白项目开始创建第一张可用看板。
   - 路径 B：从模板开始创建第一张可用看板，并修改示例卡。
5. 观察指标必须覆盖：
   - 是否完成创建
   - 创建耗时
   - 卡住点
   - 是否理解列结构
   - 是否理解示例卡
   - 是否能把示例卡改成自己的任务
   - 是否觉得模板打扰或有帮助
6. 必须提供一张可直接使用的记录表模板。
7. 必须明确：当前阶段不会输出真实研究结论，只输出研究计划；真实结论需等执行研究后再补。
