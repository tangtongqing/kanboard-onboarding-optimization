1. 文档标题使用 `# 设计系统整理 PD-009`。
2. 必须在开头标注：`版本性质：假设版 / 待研究验证版 / 高保真前置设计输入`。
3. 必须明确说明：PD-009 是设计系统整理草案，不是最终视觉系统、正式 Figma Library 或工程组件实现。
4. 必须包含以下章节：

   - 组件规范

   - 待研究验证与后续进入 PD-010 / Product Design / Figma 的输入
5. `现有视觉系统盘点` 必须结合 `styles.css`、`index.html`、`app.js` 和 `设计图/` 中已存在的界面与图，不要只写抽象原则。
6. `设计 Token 草案` 至少覆盖：
   - 颜色：主色、文字色、辅助文字色、背景色、面板色、边框色、成功色、警告色、错误色、选中态色、禁用态色。

   - 间距：页面边距、弹窗内边距、组件间距、表单间距、卡片间距。
   - 圆角：按钮、输入框、卡片、弹窗、标签。
   - 阴影：弹窗、浮层、卡片 hover。
   - 边框：默认、hover、focus、error、selected。
   - 层级：页面、弹窗、下拉/浮层、确认对话框、提示反馈。
7. `组件规范` 至少覆盖：
   - 主按钮 / 次按钮 / 危险按钮 / 文本按钮
   - 输入框 / 文本域 / 必填错误

   - 模板预览区域

   - 标签 / 徽标 / 辅助提示
