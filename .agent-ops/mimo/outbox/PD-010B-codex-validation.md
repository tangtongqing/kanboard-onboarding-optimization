## 1. 初始交付问题

1. 回传先称新增测试有 32 个断言，后又称 25 个，统计口径不一致。
2. 修复前运行在第一个 R11 断言失败后即停止，没有分别留下 R06/R08/R14 的实际失败输出；只能证明断言已写入，不能证明每项都独立经历红灯。
3. 回传声称测试没有固定延时，但新增测试继续调用现有 `pause()`，其实现为固定 120ms `setTimeout`。
4. R11 只验证新建与即时渲染，未验证重载持久化，也未处理旧 localStorage 中缺少 `isExample` 字段的模板卡。
5. R14 未覆盖底部“取消”按钮、创建方式变化和模板选择变化的 dirty 判定。
6. R08 只测滚动到底后的底栏位置，未覆盖初始和中间滚动位置。
7. 回传提到的导入测试波动在 Codex 复跑时实际复现：Playwright `fill()` 向 textarea 写入超长项目 JSON 时超时。

## 2. Codex 修订

- 新增 R11 重载持久化测试，并在 `normalizeState()` 中根据既有“由「…」模板生成”活动记录迁移旧数据。
- 新增旧数据迁移后的徽标渲染断言。
- 新增 R14 底部取消、创建方式变化、模板选择变化的确认与保留输入测试。
- 将 PD-010B 新增路径中的固定 `pause()` 改为状态条件等待。
- 将 R08 扩展为顶部、中部、底部三个滚动位置均保持操作区在视口内。
- 将超长导入 JSON 的测试输入改为页面上下文赋值并派发 `input` 事件；业务预览与导入按钮流程保持不变。
