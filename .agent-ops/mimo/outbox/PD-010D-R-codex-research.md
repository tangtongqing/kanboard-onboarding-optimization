初始搜索接口返回 403，随后改用 GitHub CLI、GitHub API、Hacker News Algolia API 和官方文档直接查询。Reddit 未获得稳定结果，已在主报告标为来源缺口。

## 2. 研究纪律

- 没有创建 P01~P08、参与者引语、评分、耗时或偏好票数。
- 同一公开作者的多条评论不重复计算为多人信号。
- 明确区分 `[公开事实]`、`[跨源模式]`、`[推断]` 与 `[模拟]`。
- 早期模板 issue 只作为长期需求信号，不描述为当前发生率。
- 所有对 V03~V06 的方案判断均保留置信度和反例。

## 3. 方向性结果

- V03：支持精简默认 + 渐进披露，不支持用单一密度覆盖团队和个人用户。
- V04：分区预览方向得到界面理解与复制完整性证据支持，但仍无真实复述测试。
- V05：公开证据无法裁决默认模板/空白和名称位置，继续低置信暂定。
- V06：移动端风险证据强，但无法裁决全屏与 16px 边距；sticky、触摸目标、滚动和真机验证优先。
- R14：未保存关闭保护获得直接外部证据支持。

## 4. Gate

PD-011 已按项目范围决策调整为 `Go（二手研究口径）`。允许在 3 个视觉方向选定后进入高保真，但不允许把公开二手研究或模拟画像包装成真人测试结论。
