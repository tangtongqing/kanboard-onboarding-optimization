本轮补齐依据
Authentication Providers 通过 AuthenticationManager 注册，实现 Password、OAuth、Pre、Post 或 SessionCheck 接口。
Automatic Actions 动作类继承 Action\Base，实现兼容事件、必填参数、条件和 doAction。
Notification Types 通过 user/project notification type model 注册处理器，并实现 NotificationInterface。
Custom Forms 通过 modal、form helper、controller POST 处理、错误回显和 redirect 构建插件表单流程。
Authorization / Custom Routes 通过 applicationAccessMap、projectAccessMap 与 route->addRoute 补齐插件页面权限和 URL 映射。
Providers 覆盖 Avatar、Group、External Link、External Task 与 Mail Transport 等插件 provider 注册点。
Schema / Helpers / Events / Overrides 覆盖 Schema 迁移、helper 注册、事件注册监听、模板/CSP/formatter override。
